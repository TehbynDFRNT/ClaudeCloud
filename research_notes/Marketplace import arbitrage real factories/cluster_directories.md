# Real manufacturers in six Chinese industrial clusters: directory and government-list cross-check

Researched 2026-10-10 (UTC). Scope: trampolines; weights (bumper and cast-iron plates, kettlebells, dial dumbbells); hammock stands and outdoor-leisure steel; electric standing-desk frames and columns; timber cubby houses; aluminium camp kitchens. For each cluster the aim is to list manufacturer names that a cross-checker can search in an association list, government list, exhibitor list or certification directory, so they can test whether a supplier on Alibaba or Made-in-China is a factory or a reseller.

Conventions: names are copied as the source prints them. Each name carries the URL it came from. Anything that could not be found is under Gaps, not filled in.
